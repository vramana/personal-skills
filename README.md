# personal-skills

A Claude Code plugin with my personal skills.

| Skill | What it does |
|---|---|
| `demo-video` | Records a 60–100s demo video of a feature in the real frontend, with faked backend and a fixed overlay/caption style. |
| `simple-artifact` | Explains a change with diagrams (before/after, commit stacks with risk tags) and few words. |
| `ui-hillclimb` | Improves a web UI in small scored rounds: fast screenshots of every screen and part, honest absolute ratings, before/after in one living artifact. |

## Install

```
/plugin marketplace add vramana/personal-skills
/plugin install personal-skills@vramana-personal
```

Skills are then available as `/personal-skills:demo-video`, `/personal-skills:simple-artifact` and `/personal-skills:ui-hillclimb`.
